- [ ] Verify canonical privacy policy and outbound links against Public URL Register
- [ ] Confirm brand/logo visual approval, image copyright/provenance and alt text
- [ ] Netlify detects both forms, notifications and acknowledgements configured
- [ ] Send valid/invalid/spam contact submissions, verify actual receipt and confirmation
- [ ] Send broken-link report, verify URL/referrer/time and actual receipt
- [ ] Confirm unknown URL returns 404 (not 200 or 302)
- [ ] Verify keyboard, screen reader, 320/375/390 widths and physical iPhone
- [ ] Verify HTTPS, DNS, Netlify release and rollback
- [ ] Register HTML pages and release evidence; only then update newsletter footer
